# Checklist de buenas prácticas

- Define el objetivo con precisión.
- Añade contexto relevante y acotado.
- Especifica el formato solicitado.
- Limita la respuesta si hace falta.
- Pide revisión o mejora iterativa cuando el resultado no sea suficiente.
- Guarda prompts que funcionen bien.
- Prueba variantes del mismo prompt para aprender.
